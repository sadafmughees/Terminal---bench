# Project Insight — Science: Physics Lattice Diffusion

2D nonlinear steady-state lattice heat conduction, thermal runaway fold bifurcation, linear stability eigenvalue analysis, and Method of Manufactured Solutions (MMS) verification implemented with JAX.

## Dataset
This computational physics benchmark uses standard crystalline silicon thermophysical constants ($\rho = 2330\,\text{kg/m}^3$, $c = 700\,\text{J/(kg}\cdot\text{K)}$, $\kappa_0 = 150\,\text{W/(m}\cdot\text{K)}$) and analytical boundary-value formulations; no external dataset files are required.
